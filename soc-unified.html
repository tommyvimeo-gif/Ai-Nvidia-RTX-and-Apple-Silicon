SoC in Unified Memory

Kako integracija komponent in skupni pomnilnik spreminjata način, kako računalniki delujejo.

Kaj je SoC (System on a Chip)?

SoC pomeni, da so številne ključne komponente računalnika integrirane v en sam čip:

  • CPU jedra
  • GPU (grafični procesor)
  • Neural Engine / NPU
  • pomnilniški krmilniki
  • video kodeki, I/O krmilniki in drugi pospeševalniki

Pri starejšem Intelovem Macu je bila sestava ločena. Pri Apple Silicon in podobnih sistemih so komponente združene v en SoC.

Kaj je Unified Memory?

CPU, GPU in AI-pospeševalniki delijo isti fizični pomnilnik. Ni več ločenega sistemskega RAM-a in ločenega VRAM-a.

Klasični PC z ločeno grafiko

CPU ──► Sistemski RAM (npr. 32 GB) │ ▼ (prenos prek PCIe) GPU ──► Ločeni VRAM (npr. 16 GB)

Podatki se pogosto kopirajo med RAM in VRAM.

Sistem z Unified Memory

SoC ┌─────────────────┐ │ CPU GPU AI │ │ │ │ │ Skupen │ │ pomnilnik │ └─────────────────┘

CPU in GPU dostopata do istega pomnilnika – manj kopiranja.

Ali 16 GB Unified Memory pomeni 16 GB VRAM-a?

Ne povsem. Gre za 16 GB skupne fizične kapacitete. GPU lahko dostopa do več pomnilnika kot pri ločeni kartici z npr. 8 GB VRAM-a – koristno za 3D, video in lokalne AI-modele.

Skupni pomnilnik ni čarovnija: enote tekmujejo za pasovno širino. Del prostora zaseda OS in aplikacije.

Zakaj konzole to uporabljajo že dolgo?

PS5 in Xbox Series X sta že 2020 pokazala učinkovitost skupnega pomnilnika (16 GB GDDR6). Več na Konzole & APU.
