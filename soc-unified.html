SoC in Unified Memory

Kako integracija komponent in skupni pomnilnik spreminjata način, kako računalniki delujejo.

Kaj je SoC (System on a Chip)?

SoC pomeni, da so številne ključne komponente računalnika integrirane v en sam čip: CPU, GPU, Neural Engine / NPU, pomnilniški krmilniki in drugi pospeševalniki.

Kaj je Unified Memory?

CPU, GPU in AI-pospeševalniki delijo isti fizični pomnilnik. Ni več ločenega sistemskega RAM-a in ločenega VRAM-a.

Klasični PC

CPU → Sistemski RAM ↓ (PCIe) GPU → Ločeni VRAM

Unified Memory

SoC: CPU + GPU + AI ↓ Skupen pomnilnik
Skupni pomnilnik ni čarovnija: enote tekmujejo za pasovno širino. Del prostora zaseda OS.
