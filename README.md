# Ai Nvidia RTX and Apple Silicon

Spletna stran (v slovenščini) o **veliki spremembi arhitekture računalnikov**: od klasičnega x86 PC-ja do ARM, SoC in **Unified Memory**.

## Vsebina

- **x86 vs ARM** – procesorski arhitekturi
- **SoC & Unified Memory** – kaj pomenita in zakaj sta pomembna
- **NVIDIA DGX Spark / RTX Spark** – Grace CPU + Blackwell GPU + do 128 GB Unified Memory, 1 PFLOP AI
- **Apple Silicon** – Mac Studio M5 Ultra, M6 (2 nm), MacBook Neo (A18 Pro)
- **Microsoft Surface Laptop Ultra** – Windows on Arm z RTX Spark
- **Igralne konzole** – PS5 in Xbox Series X z APU in skupnim GDDR6
- **Mini PC-ji** z Unified Memory
