NVIDIA DGX Spark & RTX Spark

ARM Grace CPU + Blackwell GPU + do 128 GB koherentnega Unified Memory – lokalni AI superračunalnik v majhnem ohišju.


Kaj je DGX Spark / RTX Spark?

NVIDIA je z platformo Grace Blackwell (GB10 / N1X) ustvarila integriran sistem, ki ni običajen PC z ločenim Intel/AMD procesorjem in ločeno grafično kartico RTX. Gre za SoC, ki združuje:

  • ARM Grace CPU – do 20 jeder (10× Cortex-X925 + 10× Cortex-A725),
  • Blackwell GPU – do 6.144 CUDA jeder, 5. generacija Tensor jeder, 4. generacija RT jeder,
  • do 128 GB LPDDR5X Unified Memory – koherenten skupni pomnilnik za CPU in GPU,
  • do približno 1 PFLOP FP4 AI zmogljivosti (s sparse).

Zakaj je Unified Memory tukaj tako pomemben?

Pri klasičnem računalniku imaš 32 GB sistemskega RAM-a in grafično kartico z 16 GB VRAM-a – to sta ločena sistema. Model AI mora biti omejen na VRAM ali pa se uteži nenehno prestavljajo.

Pri DGX/RTX Spark procesor in GPU uporabljata skupen, koherenten pomnilniški prostor do 128 GB. To omogoča lokalno poganjanje večjih jezikovnih modelov (do ~100–200B parametrov), manj kopiranja podatkov in enostavnejši razvoj.

128 GB Unified Memory ne pomeni enake grafične zmogljivosti kot namizna RTX 5090. Prednost je velika kapaciteta skupnega pomnilnika + CUDA sklad. Ločena kartica ima lahko višjo pasovno širino za igre.

DGX Spark vs RTX Spark

  • DGX Spark – AI razvijalci, Linux, fiksna konfiguracija, ConnectX-7 clustering
  • RTX Spark – Windows on Arm, prenosniki (Surface Laptop Ultra itd.), igre + ustvarjanje, 24–128 GB
